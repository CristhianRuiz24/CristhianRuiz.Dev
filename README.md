## 🛠️ Stack Tecnológico

- **Core Frontend:** HTML5 Semántico + JavaScript ES6+ Vanilla (Modular).
- **Estilos & Diseño:** CSS3 Nativo con Custom Properties, Grid/Flexbox con salvaguarda `minmax(0, 1fr)` para cero desbordamiento en smartphones.
- **Iconografía:** SVGs vectoriales nativos con efectos neón (cero dependencias de fuentes de iconos externas o emojis de sistema).
- **Backend / Edge Functions:** Cloudflare Pages Functions (`/functions/api/contact.js`) para procesamiento seguro de formularios.
- **Integración de Correo:** Resend API para entrega de mensajes transaccionales.
- **Hosting & CDN:** Cloudflare Pages (distribución Edge global, HTTPS y compresión Brotli/Gzip automática).
- **SEO & Performance:** Meta-tags Open Graph, Twitter Cards, Schema.org estructurado, `robots.txt`, `sitemap.xml` y tiempos de carga instantáneos (FCP < 1.0s).

## 🚀 Ejecución en Entorno Local

Para levantar el proyecto en un servidor local de desarrollo:

### Opción 1: Con `serve` (Node.js)
```bash
npx -y serve .
```

### Opción 2: Con `live-server`
```bash
npx -y live-server .
```

### Opción 3: Con Python 3
```bash
python -m http.server 8080
```

Abre tu navegador en `http://localhost:3000` (o el puerto indicado) para interactuar con la plataforma.

## 📐 Metodología de Desarrollo

Este proyecto sigue estrictamente el flujo **Spec-Driven Development (SDD)**:
1. **Constitución (`docs/constitution.md`):** Principios innegociables de copy, arquitectura y estética.
2. **Especificación EARS (`specs/001-landing-page-crisdev/spec.md`):** Requisitos funcionales y no funcionales estructurados antes de implementar código.
3. **Control de Calidad:**
   - Verificación en viewports móviles (375px - 430px) y desktop (1200px+).
   - Cero errores en consola JavaScript.
   - Rendimiento optimizado sin frameworks pesados.
